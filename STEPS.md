# How to Run the Application

Follow these simple steps to run the application on your computer.

---

### Step 1: Open Command Prompt in this folder
1. Open this project folder in File Explorer.
2. Click on the address bar at the top, type `cmd`, and press **Enter**.

---

### Step 2: Start the Application
Type the following command and press **Enter**:

```cmd
run_app.bat
```

*(Alternatively, you can just double-click `run_app.bat` in the folder).*

Wait until you see this line in the command prompt:
```text
* Running on http://127.0.0.1:5000
```

---

### Step 3: Open in Your Browser
Open your browser (Chrome, Edge, etc.) and go to:
👉 **http://127.0.0.1:5000**

---

### Step 4: How to Test
1. Click **Browse** and select `demo/sample_test.dcm`.
2. In the text box, type:
   > *Normal chest x-ray with clear lungs.*
3. Click **Run Analysis**.

---

### To Stop the Application
Press `Ctrl + C` in the Command Prompt window.
